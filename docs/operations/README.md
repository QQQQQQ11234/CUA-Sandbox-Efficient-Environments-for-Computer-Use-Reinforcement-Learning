# Operational notes

These runbooks capture deployment and validation details for the current
PostgreSQL/GitLab and MySQL/XFS integrations. Start with
[MYSQL_QUICKSTART.md](MYSQL_QUICKSTART.md) for Shopping/CMS. The architecture
and portable configuration are documented one level up in
[../architecture.md](../architecture.md) and [../configuration.md](../configuration.md).

The benchmark result files produced by these runbooks belong in ignored local
output directories; the notes here describe the procedure and assumptions,
not a guaranteed result on another host.
